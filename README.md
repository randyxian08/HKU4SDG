# 数字扶手｜HKU4SDG

数字扶手是一个黑客松产品概念：在用户自己的手机上，依据人工审核过的操作流程，圈出当前可执行的下一步，并用文字和语音解释，让用户亲手完成日常任务。目标是帮助不熟悉智能手机操作的人完成任务，也逐渐建立再次独立操作的信心。

仓库现在包含 Android 原生原型。`guide` 是引导应用，`demo-target` 是**另一个独立的虚构练习应用**，用来验证跨应用读取和提示。当前代码尚未在长者的真实设备或真实系统设置上验证，也没有用户测试结果。

## 拟定的 MVP

- 在指定 Android 设备上，引导完成一项真实系统任务，例如调整字体大小；实际点击和拖动由用户完成。
- 用自建的模拟流程验证页面变化、偏离处理和私人步骤暂停；模拟流程不产生真实预约或交易。
- 支持普通话、粤语、英语的输入、AI 回复文字和语音播报，三个语言设置可分别选择。语音不可用时保留文字输入和任务卡。
- 引导页同时提供圈画、可折叠的大字文字卡片和可选语音。卡片默认展开，收起后仍可随时查看；安全提示不会被折叠隐藏。
- 对无法确认的页面停止指引；流程与语言文案需要审核，并在目标设备上测试后才能宣称支持。

产品范围和验收建议见[飞书产品文档](https://my.feishu.cn/wiki/FTF5wKcn0iNra6kG2WpcfiZ2nCg)。该文档可能需要飞书访问权限。

## 本地运行

需要 Android Studio、Android SDK Platform 35、Build Tools 35、Platform Tools 和 JDK 17。macOS 开发机可执行：

```bash
source scripts/dev-env.sh
./gradlew :guide:assembleDebug :demo-target:assembleDebug :guide:testDebugUnitTest
./scripts/install-demo.sh
```

`install-demo.sh` 需要已连接并允许 USB 调试的 Android 设备或正在运行的模拟器。Android Studio 也可直接打开仓库根目录，先在 **Settings → Build Tools → Gradle** 选择 JDK 17，再分别安装 `demo-target` 和 `guide`。首次使用时，在系统无障碍设置中手动开启“数字扶手 · 练习引导”；用户需要自己完成这一步。

打开数字扶手后，可选择三种独立语言，用任务卡或文字进入练习场。练习场的“显示设置”→“字体大小”→滑块是虚构流程，不会修改手机系统字体。引导应用只读取练习场的已登记控件 ID；其他应用的窗口变化仅用于撤下旧圈画，不读取其页面内容。页面上有可收起的文字卡片、圈画、重播和静音。“模拟陌生页面”会停止圈画；“模拟私人步骤”会暂停引导，返回普通页面后仍须手动点“继续”并重新检查。

语音识别和合成调用设备提供的服务；首次点按语音输入会单独说明音频可能由设备服务联网处理。粤语可用性及自然度尚未实测。当前任务匹配是有限的本地规则，**不是 AI 模型**。真实 Android 设置流程、AI 意图理解、真机无障碍测试和用户试用仍是后续任务；见 [MVP 开发计划](docs/mvp-plan.md)。

## 一起协作

功能、设计、研究和文案讨论都可以开 Issue。认领工作前先写清目标、预期产物和验收方式；提交代码或文档时使用 Pull Request，附上做了什么、如何验证以及仍未验证的部分。具体约定见 [CONTRIBUTING.md](CONTRIBUTING.md)。

不要提交真实用户的录音、截图、身份资料、密钥或服务凭据。演示与测试使用虚构数据。
