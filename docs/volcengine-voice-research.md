# 数字扶手｜火山引擎语音与受控 AI 选型

调研日期：2026-09-28。以下是官方接口可行性与团队实施建议，**尚未开通服务、接入云 API 或完成三语试听**。本次黑客松以 Android 15 / Pixel 7 模拟器为演示设备；演示证据如实标记为模拟器运行。

## 先做哪一段

先把「说出目标 → 看见识别文字 → 用户确认任务 → 在真实系统设置里亲手完成 → 收到完成反馈」做成可演示的单 App 闭环。界面与功能要一起沿这条路径打磨，不等所有页面都完美才接 AI，也不先接一个会自由生成操作步骤的语音聊天模型。

第一段界面要补齐待机、收音、识别结果预览、无法识别、用户确认、引导暂停和完成状态。始终允许手动输入与任务卡继续。语音相关能力分开替换：

```text
用户说话 ── ASR ── 用户可编辑的文字 ── 受控意图识别 ── 已审核任务 ID
                                                         │
                                             用户确认 + 已审核步骤
                                                         │
                                独立的引导文字语言 ── 独立的 TTS 播报语言
```

此处的 AI 只解决「用户说的是哪个已支持任务」；模型不生成跨应用坐标、不编造新步骤，不代替用户点击。支持范围、页面验证和完成条件由本地已审核任务决定。

## 官方接口与适用判断

| 需求 | 官方能力 | 对本项目的判断 |
|---|---|---|
| 普通话、粤语、英语语音输入 | [流式识别 2.0 选型](https://docs.volcengine.com/docs/DoubaoVoice/Accessmust-read_1?lang=zh)区分一句话识别 `bigmodel_nostream` 与实时识别 `bigmodel_async`；[单向 WebSocket API](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-automatic-speech-recognition-websocket?lang=zh)列出 `zh-CN`、`yue-CN`、`en-US`。 | MVP 是按住/点击说一句任务，优先试稳定的 `bigmodel_nostream`；结果先让用户看见和修改，再交给任务匹配。现有 App 内粤语标签为 `yue-HK`，接火山接口需明确映射到 `yue-CN`，不能直接传过去。 |
| 三语播报 | [TTS HTTP API](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-text-to-speech-http?lang=zh)有语种参数及 `explicit_dialect=yue`；使用粤语参数须选择支持方言的音色。 | 普通话、英语先以短句验证。粤语必须核对账号可用音色并由粤语使用者试听，再标为可用；接口列出参数不等于当前账号已有自然粤语播报。播报只读已审核文案；失败时保留可折叠文字卡。 |
| 自然语言理解 | [方舟 Chat API](https://docs.volcengine.com/docs/ark/chat-api?lang=zh)支持部分模型的结构化 `json_schema` 响应，官方标明该能力存在 beta 限制。 | 只输出 `task_id`、`clarify`、`unsupported`，服务器或 App 再按允许列表验证；与现有关键词规则用同一组三语样例对照。没有模型结果前不宣称已经接入 GenAI。 |

不在第一轮接入端到端实时语音对话：当前产品需要独立控制输入、文字与播报语言，还需要用户确认及固定步骤。模块化管线更容易逐项验证错误和保留文字退路。这个顺序是团队的产品判断，不是官方对各模型效果的承诺。

## 最小接入与验收

1. **无云密钥也可完成的界面闭环**：完善收音/预览/确认/失败状态；沿用文字输入和现有系统任务。录屏证明用户始终能检查识别结果、取消、重试，且权限拒绝后还能完成任务。
2. **ASR 小样本验证**：在模拟器分别提交普通话、粤语、英语的短句，记录原话、转写、耗时、失败情况。验证 `yue-HK` 到 `yue-CN` 的适配。与系统 `SpeechRecognizer` 的同句结果作对照，再决定是否替换默认路径。
3. **受控 AI 意图**：先编一组「字体调整」「容易混淆」「范围外」三语测试句；模型只从已审核任务清单选择，未知/低把握则请求澄清。记录误匹配、拒绝率与延迟；不能仅展示几个成功例子。
4. **TTS 审听**：对每种播报语言合成相同含义的短指引；记录音色、音量、语速、发音问题和无声/失败退路。粤语需真人审听，不以 `explicit_dialect=yue` 参数存在代替验证。
5. **演示回归**：在 Android 15 / Pixel 7 模拟器走完整主路径、拒绝麦克风、云服务超时、网络断开、未知页面、TalkBack 和大字模式。标明“模拟器验证”及系统版本，不外推其他设备。

调用云 API 前需在火山控制台核对该账号的新/旧控制台、已开通资源、鉴权方式、音色与实际计费；服务密钥不写入公开仓库或 APK。可由一个最小代理持有密钥，用户仍只安装一个 Android App。语音上传须在界面明确提示并取得使用者主动触发；默认不保存原始录音或页面内容。

实现分工可落在现有 [三语能力 Issue #2](https://github.com/randyxian08/HKU4SDG/issues/2) 与 [受控 AI Issue #4](https://github.com/randyxian08/HKU4SDG/issues/4)，不另起一套重复任务。
