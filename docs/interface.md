# 数字扶手｜Android MVP 界面

这版界面围绕一句话设计：**用户亲手操作，数字扶手只指出下一步。** 首页要让人知道自己将练什么；进入另一个 App 后，圈画必须准确，文字和语音随时可用，私人或陌生页面必须清楚地停下来。

## 用户看见的三个层次

1. **出发：首页。** 首屏呈现一件可开始的任务、引导服务状态和主要按钮。文字或语音输入是另一种入口；输入、屏幕文字和播报语言在下方分别设置。当前只有“把字调大”的模拟练习，不能暗示能指导任意 App。
2. **途中：跨应用指引。** 练习场是单独安装的 App。数字扶手在它上面用带步骤编号的橙色圈画标出目标，并用卡片说明当前动作。卡片避开当前目标；文字默认展开，可以收起。用户可重播、静音或结束，实际点击和拖动仍由用户完成。
3. **停下：私人或陌生页面。** 私人页面撤下圈画和播报，显示暂停原因；返回普通页面后，用户还须手动继续。陌生页面停止圈画并说明无法确认下一步。完成后显示单独的结束状态。

视觉采用浅米白背景、深绿色主色和暖橙色步骤标记。大标题帮助快速定位，正文和操作区保持清楚的对比与留白；橙色只用来指出需要注意的位置，不表示已经自动操作。

## 后续界面验收

- 在一台指定真机上检查状态栏、系统导航区、较小屏幕、1.4 倍字体和 TalkBack 顺序。
- 在真实 Android 设置页验证圈画位置、卡片避让、页面变化和返回路径。
- 找目标用户走一遍，不提示他们该按哪里；记录找不到入口、看不懂文字、听不清播报和被卡片遮挡的时刻，再调整布局与文案。

当前界面和代码仍是黑客松 MVP，不是任意 App 通用引导，也没有 AI 生成的操作步骤。
