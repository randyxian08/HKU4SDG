# Android MVP 开发计划

目标是黑客松里可以诚实演示的 90 秒闭环。每个阶段以可观察结果验收，保留失败记录。

| 顺序 | 结果 | 验收 |
|---|---|---|
| 1 · 跨应用骨架 | 在独立练习场识别登记控件，显示圈画与可折叠文字，用户亲手操作 | 真机上圈画位置正确、不挡按钮；离开已登记页面立即撤掉旧指引 |
| 2 · 安全暂停 | 模拟私人步骤停止页面分析和语音，返回后手动继续 | 暂停中无圈画、无播报；仅点击“继续”不能在私人页恢复 |
| 3 · 三语 | 输入、文字、播报独立选择；检查普通话、粤语、英语 | 文字/语音各自对应选择；不支持的本机语音明确提示，文字仍可用 |
| 4 · 真实任务 | 在选定设备的 Android 设置中完成“调大字体” | 记录机型、系统版本、控件 ID 和真实字号变化；遇未知页停止 |
| 5 · AI 与试用 | 把多语自然表达映射到已审核任务，并做小规模观察 | AI 只输出登记任务 ID；展示错误、拒绝和人工介入结果，不把模拟数据算成效果 |

阶段 1 的代码已在 Android 15 / Pixel 7 模拟器上完成跨应用圈画、逐步更新、文字折叠、模拟陌生页停指引，以及离开练习场撤下圈画的检查；仍待真机验收。阶段 2 的模拟私人页暂停、在私人页拒绝继续、返回后手动继续也已在该模拟器上检查。阶段 3 的文字语言与播报语言独立设置已在模拟器验证；真人语音识别和粤语播报质量尚未验证。阶段 4、5 尚未实现。演示时要明确区分这些状态。

## 真机检查单

1. 安装两个 APK，记录手机型号、Android 版本、文字缩放和 TalkBack 状态。
2. 手动开启引导服务。拒绝麦克风后，用任务卡仍能开始。
3. 在练习场从“显示设置”走到滑块，逐步确认圈画、卡片展开/折叠、语音/静音、原生按钮仍可触碰。
4. 前往未登记页面，检查旧圈画消失；进入模拟私人页，检查提示暂停，返回后手动继续。
5. 逐项试听普通话、粤语、英语，记录缺失语言包、识别错误和 TTS 发音问题。只有实测通过的组合才能放进答辩的已实现清单。

## 分工建议

- Android 核心：页面识别、浮层、真机兼容与安全暂停。
- 语言体验：三语文案审核、真人试听、ASR/TTS 失败退路。
- 产品验证：练习脚本、匿名观察、演示记录与问题清单。

所有任务从 GitHub Issue 认领；每个 Pull Request 只围绕一个可验收结果。主分支由 CI 编译和至少一位队友审阅保护。
