# AI 与三语语音：比赛演示与验收

核对日期：2026-10-17。Android 测试版：0.1.3 / versionCode 4。基准：`main` 的 `1b77ef7`。

## 先回答：有没有接入模型

已经接入。用户说出或输入目标后，豆包 `doubao-seed-2-0-mini-260428` 理解普通话、粤语或英语，输出匹配任务、请求澄清或暂不支持。语音识别使用火山 ASR，固定引导的播报使用火山 TTS 2.0；识别、文字、播报三项语言可以分别设置。

这是调用云端模型的 Android 原型。Debug 模拟器通过 `10.0.2.2:8765` 访问电脑上的代理，代理只监听 `127.0.0.1:8765`，密钥保留在电脑。模型权重没有装进 APK。单独安装到手机、未连接电脑的 APK 仍使用本地匹配和设备语音服务；本轮没有交付面向手机的云端网关。

## 10 月 17 日修正了什么

首次恢复代理后，真实模型可返回正确任务，但三种 TTS 请求均被旧代理判成失败。真实 HTTP 响应含 `code=0` 音频，正常结束却没有旧实现要求的 `20000000` 标记。[当前官方接口](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-text-to-speech-http?lang=zh)以 `code=0` 音频响应为例，因此代理改为接受正常 HTTP 结束，并兼容旧标记。空音频、HTTP 截断、错误码和非法编码仍失败；供应商响应解析错误归为上游不可用，不当作用户输入错误。

另外补充了：

- 安全读取本机 `.env` 的代理启动入口，不执行其中的 shell 命令，不打印凭据。
- `/health` 中的模型名称和进程内调用计数；这些是配置与请求尝试记录，不代表供应商账单或实际成功次数。
- 显式 `--live` 的三语接口回归，输出合成目标、识别文字、结构化决策和延迟；失败返回非零退出码。
- Android 原生检查：三语非关键词目标、澄清、拒绝、私人内容拦截及云端播放器启动；另以代理停止状态验证退路。
- 目标确认页区分真实 AI 结果、本机匹配和直接选择任务卡。云端音频接收在读取过程中限制大小，临时播放文件在停止／结束时删除。

## 团队如何复现

已配置 `.env` 和 `.venv` 的电脑，在仓库根目录启动：

```bash
.venv/bin/python scripts/start-ai-demo.py
```

该终端需保持运行。端口已被占用时脚本退出，不会停止其他进程。缺少配置时只显示字段名；配置方法见[开发指南](development.md)。另开终端：

```bash
# 只检查配置，不调用供应商：
.venv/bin/python scripts/check-ai-demo.py
# 真实调用：可能产生用量；仅使用脚本内置的合成示例，需要 ffmpeg：
.venv/bin/python scripts/check-ai-demo.py --live \
  --output captures/ai-live.json --audio-dir captures/ai-audio
```

一次完整 live 回归包含 6 次 TTS、3 次 ASR、6 次模型请求，以及 1 次在代理本地拦截的虚构私人请求。失败的请求也可能产生供应商用量。音频文件来自测试合成，不是用户麦克风录音。

App 检查需要 Android 15 模拟器、已安装 Debug／开发检查 APK，数字扶手服务原本已开启，且无活动引导：

```bash
source scripts/dev-env.sh
python3 scripts/run-device-check.py ai
# 在代理终端按 Ctrl-C 停止后，再运行：
python3 scripts/run-device-check.py ai-offline
```

`ai` 会调用真实云端模型和三语 TTS，可能产生用量；`ai-offline` 要求代理停止。设备检查不伪造麦克风输入，不自动提交转写文字，也不执行未审核任务。脚本恢复原应用偏好和记录；测试过程会重启应用进程。

## 给评委的简短叙事

> 长者可能知道想达到什么效果，却不知道设置功能的名称。数字扶手先把语音转为可检查的文字，再由生成式模型理解需求。需求不明确时先澄清；理解后选择团队审核过的引导。用户亲手完成操作，应用用圈画、文字和语音陪伴每一步。模型负责理解表达，本地逻辑约束操作范围，完成结果还要由用户确认。

用一次实际运行的非关键词请求、一个模糊请求、一次代理关闭后的退路，展示 GenAI 的用途和限制。[历史 51 条合成开发集对照](intent-evaluation.md)可作为补充，不能称为今天重跑的结果或真实长者准确率。

实际结果、失败记录、构建标识与截图见[本轮验收](validation/ai-voice-2026-10-17.md)。真人麦克风识别、三语使用者的音质／理解度审听、完整用户闭环和手机云端部署仍须另行验收。
