## 首次失败与修正后结果

[修正前记录](ai-voice-2026-10-17-before-fix.json)：三种语言的 TTS 均返回代理 502，后续音频链路没有执行；模型的澄清、拒绝、对抗表达及代理私人内容拦截通过。直接检查供应商 HTTP 响应确认已有 `code=0` 音频，但没有旧实现要求的结束标记。按当前接口修正后，不再把正常 HTTP 结束判为失败。

[中间回归](ai-voice-2026-10-17-intermediate.json)：普通话与粤语完整通过，英语 TTS 出现一次代理 400。该次上游原始响应未保留，无法确定原因。随后英语供应商直连及 Android 播放成功。代码补充了将上游 JSON／编码异常归为供应商不可用的处理与测试；这不证明该次 400 就是格式错误。

[最终真实接口回归](ai-voice-2026-10-17.json)：7 个检查通过，包括三条 TTS→ASR→模型→TTS 链路、模型澄清、范围外拒绝、对抗表达拒绝及代理私人内容拦截。最后一项在代理本地处理，不算模型拒绝。共 6 次 TTS、3 次 ASR、6 次模型请求。

| 输入语言 | 合成目标经 ASR 返回 | 模型任务 | 目标 TTS / ASR / 模型耗时 |
|---|---|---|---|
| 普通话 | 我想把手机上的字调大。 | `font_size` | 5.653 / 5.630 / 1.542 秒 |
| 粤语 | 我想调光啲个手机屏幕。 | `screen_brightness` | 3.169 / 5.010 / 1.777 秒 |
| 英语 | I want larger text on my phone. | `font_size` | 2.269 / 5.740 / 4.480 秒 |

这些耗时来自各一次合成样本请求，包含代理与网络等待，不是首音频延迟、服务 SLA 或真人准确率。返回引导的三段 MP3 也通过 `ffmpeg` 解码；音频 SHA-256 保存在 JSON。没有为了得到通过而更改预期任务，修正前及中间失败记录仍保留。

## 尚未验收

没有完成真人麦克风三语识别、母语使用者审听、完整 TalkBack 手势、长者可用性或学习效果研究，也没有把云端代理部署为手机可访问的服务。既有手机服务自行关闭的根因、自动亮度实际开关及任意第三方 App 兼容性仍未解决，见 [0.1.2 验证边界](reliability-2026-10-09.md)。

本轮没有重新运行历史 51 条模型开发集，没有把本次 3 条合成语音写成 100% 泛化准确率。供应商仍可能超时、限流或返回异常，App 必须保留文字及本机退路。截图、运行和本地构建不能证明 GitHub CI、手机云端部署、正式发布或比赛提交成功。
