# 数字扶手｜受约束 GenAI 意图识别验收

飞书[产品定义](https://my.feishu.cn/wiki/FTF5wKcn0iNra6kG2WpcfiZ2nCg)提出：AI 理解不同的任务表述，但流程审核、页面准入、圈画目标和完成条件由确定性逻辑控制。目前 Android 15 / Pixel 7 模拟器中有 `font_size`（系统字体）、`screen_brightness`（系统亮度）、`chrome_bookmark`（Chrome 收藏指定 GovHK 长者服务网页）、`maps_library_address`（Google Maps 查看香港中央图书馆地址）四条已测路径；模型只能从这四项中选择、请求澄清或拒绝。

## 目前实现

- 用户输入或经语音识别转写后，在输入框内检查文字，再主动点“查找引导”。**意图接口**只接收这段目标文字与已选输入语言；不会收到录音、无障碍树、截图或页面文字。Debug 模拟器的语音输入另经火山 ASR 处理用户主动录制的音频。明显含密码、验证码、支付、医疗、长数字或邮箱的目标文字先在本机拦下；这只是保守的第一道筛查，不能声称能识别所有敏感信息。
- Debug 模拟器经宿主机回环代理调用方舟 Chat API 的 `doubao-seed-2-0-mini-260428`。模型只能给出 `match`、`clarify`、`unsupported`，且 `match` 必须对应四项已审核任务。本机再校验字段、任务 ID 与状态组合，不接受新任务、坐标或模型编造的步骤。用户仍要在任务确认页确认，并亲手完成操作。
- 模型不可用时，只对少数明确的任务表达使用保守的本地匹配；其余回到任务卡。模型回复、异常及原始输入默认不持久化。代理还会对明显敏感描述再做一次阻断；每次启动最多 60 次意图请求、每条最多 160 字。
- Default 项目的 `Doubao-Seed-2.0-mini` 已单独开通，开发密钥仅允许访问该模型。2026-09-28 的真实模型对照和 Android 模拟器三种结果路径已验证；密钥只保存在本机被 Git 忽略的 `.env` 中。服务停止、网络超时或额度用尽时仍需走本地退路。

## 2026-10-02 扩充回归

固定集已扩为 51 条：22 条支持、5 条澄清、24 条范围外／对抗表达。真实模型 51/51，本地规则 37/51；支持任务分别为 22/22 与 13/22，范围外误匹配均为 0。模型响应中位数 3.09 秒。当前逐条输入、预期、两种输出和延迟已公开保存在[JSON 证据](intent-evaluation-2026-10-02.json)，不包含凭据或真实用户资料。

这一轮新口语走查先发现：`I cannot read the small words on my phone` 被模型要求澄清；粤语“我想下次一撳就搵返個長者服務網頁”被拒绝。改进后，前者对应系统字体任务；后者因为没有指定 GovHK 来源，只请求澄清。不能擅自替用户挑选网站。泛指“帮我收藏一个网页”、Facebook 的长者网页、图片中的小字和 WhatsApp 消息仍不匹配。

上述样本用于改进提示词后回归，属于开发集；51/51 不代表盲测、真人长者识别率或泛化准确率。早期五句走查把未指定来源的收藏请求预设为 `match`，经范围检查发现这个预期不成立；本轮预期改为 `clarify`，保留了这个解释，避免把降低约束包装成识别提升。

## 固定对照与继续条件

[`scripts/intent_cases.json`](../scripts/intent_cases.json)当前包含 51 条虚构、无个人资料的普通话／粤语／英语测试句：22 条明确支持、5 条应澄清、24 条范围外或对抗表达。早期 44 条集的结果保留在下方历史记录中。正确结果必须同时匹配决策和任务 ID，不能只看是否返回 `match`。`python3 scripts/evaluate_intent.py` 只运行本地退路；配置独立 `ARK_API_KEY` 后用 `python3 scripts/evaluate_intent.py --live` 调真实模型。两者在**同一批文本**上比较准确决策、错误匹配、支持任务召回与延迟，并保留逐条失败案例。

### 早期 44 条对照（2026-09-28）

2026-09-28 同一批 44 条样本：本地退路 33/44 完全一致，支持任务 11/19，范围外请求错误匹配 0；方舟真实模型 44/44 完全一致，支持任务 19/19，范围外请求错误匹配 0，单次响应中位数 1.96 秒。模型把 3 条模糊句识别为应澄清；本地退路不能澄清，因而拒绝。这只是团队编写的小型合成集，不代表真实长者表达或统计意义上的准确率。历史逐条 JSON 输出保存在本机被 Git 忽略的 `captures/intent-eval-four-tasks.json`。当前命令使用扩充后的 51 条集；复现早期结果须使用当时的测试集与模型配置。

在 Android 15 / Pixel 7 模拟器上，英文请求 `Make the system text larger` 经真实模型进入[字体任务确认页](screenshots/android15-ai-intent-match.png)；`Make the screen brighter` 进入[亮度任务确认页](screenshots/android15-brightness-ai-match.png)，然后由用户在真实设置里完成[圈画与亮度调节](interface.md)。模糊请求 `Can you make the screen easier to read` [显示澄清](screenshots/android15-ai-intent-clarify.png)；范围外请求 `Send a text message` [显示暂不支持](screenshots/android15-ai-intent-unsupported.png)。这验证了输入到回复/任务页的演示链路，**没有**验证真实老人的理解程度、模型遇到所有隐私描述时的安全性，或未审核的跨应用任务。

### 继续验证的范围

下一次扩大样本时，范围外请求仍应**错误匹配为 0**；若出现错误，先收紧允许范围并重测。还需用不含个人资料的真实表达进行盲测，记录网络错误、慢响应和各语言的样本分母。结构化输出是接口约束，不能代替本机结果验证或用户确认。四个任务都只能覆盖已测模拟器路径；亮度处于最大值、自动亮度开启、Chrome/Maps 改版及其他系统皮肤还未验收。

方舟模型列表与 JSON Schema 支持：[官方模型列表](https://docs.volcengine.com/docs/ark/model-list?lang=zh)、[Chat API](https://docs.volcengine.com/docs/ark/chat-api?lang=zh)。开通时控制台显示该模型剩余 500,000 / 500,000 免费推理 token；额度耗尽后可能按量计费，需继续看控制台用量。语音合成 2.0 的密钥与方舟模型密钥是两个独立凭证。
